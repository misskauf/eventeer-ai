# eventeer

I want to build a product, where event manager and/ or event sales managers can work on the full cycle from receiving a request for an event to creating a personalised proposal, signing the agreement, collecting payments, briefing the hospitality team and stake holders, offering additional products and following up on the event. I want to focus on the proposal and communications with the client. 
I want the product to include a backend, where the event manager can create different spaces to book, different food and beverages packages and different extras to book, rental fees, service charges, etc. additionally there should be an option to set up basic rules for locations, such as minimum revenue for specific days of the weeks and months or minimum rental fees that help calculate the final proposal and can offer extras to the client to meet the budget and/ or propose a discount. the event manager will be able to edit the proposal and deliver it to the client in an editable form so that the client can choose the option best fitting. after the client chose the option they liked, the event manager can approve the selection or offer adjustments and afterwards send the proposal in a contract to the client. after signing the client receives a payment request based on the payment conditions. The client gets reminders if they didn't pay, and request for second installments.  I want to have a dashboard of each deal's progress in the product that can be shared with other stakeholders. 
There should be a log in for each company, and a personalisation where they can add their logo and other personalisations.
